# Мини-приложения Telegram для риелторов

Один движок на всех клиентов. У каждого риелтора своя папка с данными и свой бот.

```
engine/          движок: стили и логика, общий для всех (правим только мы)
clients/_template/   заготовка нового клиента
clients/demo/        демо-клиент с вымышленными данными, на нём проверяем изменения
clients/evgeniy/     Евгений, «Новостройки Калининграда»
worker/          сервис заявок (Cloudflare Worker), один на всех клиентов
```

Адрес приложения клиента: `https://jonieao25-create.github.io/Rieltor/clients/<id>/`

## Как добавить клиента

1. Скопировать папку `clients/_template` в `clients/<id>`, где `<id>` — латиница без пробелов, например `ivan`.
2. В `clients/<id>/data.js` поставить `clientId: '<id>'`, ник риелтора, цвет, тексты и объекты. Фото положить в `clients/<id>/photos/` (до 60 КБ каждое).
3. `index.html` в папке клиента не править: он одинаковый у всех.
4. Риелтор создаёт бота в @BotFather. В настройках бота (Menu Button и Direct Link) указать адрес из раздела выше.
5. Заявки от бота: добавить в Cloudflare секреты `BOT_TOKEN_<ID>` и `MANAGER_ID_<ID>` (id заглавными), вписать адрес сервиса в `leadEndpoint`. Риелтор один раз нажимает Start в своём боте. Пока `leadEndpoint` пустой, заявка открывает чат с риелтором.
6. Проверить на телефоне в светлой и тёмной теме, отправить тестовую заявку.

## Изменения движка

Правки в `engine/` сразу получают все клиенты. Сначала проверяем на `clients/demo/`. После правки увеличиваем `?v=` в ссылках `index.html` клиентов, иначе Telegram покажет старую версию из кэша.

## Сервис заявок

`worker/` — новый сервис `rieltor-leads`, работает для всех клиентов. Евгений пока пользуется старым сервисом `newbuilds-leads` из репозитория 1; чтобы перевести его сюда, нужны секреты `BOT_TOKEN_EVGENIY` и `MANAGER_ID_EVGENIY` и новый адрес в его `leadEndpoint`.
